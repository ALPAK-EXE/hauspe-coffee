# HausPe Coffee E-Business (UNFV)
Prototipo academico con Vite + React + React Router. Base de datos real: MySQL 8 en el servidor del equipo, accedida con Prisma ORM desde funciones serverless de Vercel (carpeta api/, un solo enrutador en api/_lib/router.js). Esquema en prisma/schema.prisma; CHECK, triggers y vistas en prisma/sql/extras.sql; datos de ejemplo en prisma/seed.mjs. El navegador usa src/db/data.js (fetch a /api); si /api/health falla, cae a la base SQLite local (sql.js, src/db) y muestra "Modo sin conexión (base local)". Variables de entorno: DATABASE_URL y SESSION_SECRET (.env.local, nunca en git). Dos áreas con sesión JWT en cookie httpOnly: clientes (/login, tabla Cliente) y personal (/admin/login, tabla Empleado, roles en src/permisos.js); la API autoriza cada ruta en el servidor. Datos mock en src/data y localStorage solo para carrito, pedidos de la vista y cosecha/tueste. Todo pago, IoT y blockchain es simulado. Mantener la paleta crema/verde bosque y las fuentes Cormorant Garamond + Inter. Usar las skills de .claude/skills.
